# formwork

**Surgical rebuilds. Serious validation. Any design system.**

A form library for Flutter built on three principles:

1. **Agnostic of design system and state management.**
2. **Surgical rebuilds.**
3. **A serious validation engine.**

See [PRINCIPLES.md](PRINCIPLES.md) for what each one means and how it is
enforced.

| Package                                         | What it is                          |
|-------------------------------------------------|-------------------------------------|
| [`formwork`](packages/formwork)                 | Engine, validation and rendering    |
| [`formwork_material`](packages/formwork_material) | Material Design field builders    |

Design documents live in [`docs/design`](docs/design).
